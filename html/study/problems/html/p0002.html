做题记录 数学 第2题

已知函数 \(f(x) = (x^2-kx+1) \ln x\) 在区间 \((0,1)\) 和 \((1, +\infty)\) 上各恰有一个零点，分别记为 \(x_1\) 和 \(x_2.\)
1. 求实数 \(k\) 的取值范围。
2. 记曲线 \(y = f(x)\) 在点 \((x_1, 0)\) 处的切线与两坐标轴围成的三角形面积为 \(S,\) 求 \(\dfrac{S}{x_2 - x_1}\) 的最大值。
3. 若函数 \(g(x) = f(x)-a\) 有三个零点 \(t_1, t_0, t_2,\) 其中 \(t_1 < t_0 < t_2,\) 证明：\(t_2-t_1 \leqslant x_2-x_1.\)

开始第一问。

首先考察函数的零点。\(f(x) = (x^2-kx+1) \ln x\) 由两部分组成：带参数的二次多项式 \(x^2-kx+1,\) 和对数函数 \(\ln x.\) 显然，对数函数的零点为 \(x = 1.\)
题目变成：考察 \(k\) 的取值范围，使二次多项式 \(x^2-kx+1\) 满足下列要求：有两个零点，且两个零点分别位于 \((0,1)\) 和 \((1, +\infty)\) 上。
先考察满足二次多项式有两个零点的情形。由二次多项式的性质，可得不等式：\(\Delta = k^2-4 > 0.\) 解不等式，得：\(k > 2\) 或 \(k < -2.\)
再考察两个零点的范围。因为 \(0 < x_1 < 1, x_2 > 1,\) 所以 \(x_1+x_2 > 1.\) 由韦达定理，可得：\(k > 1.\)
综合，可得 \(k\) 的取值范围为 \(k > 2.\)


开始第二问。
